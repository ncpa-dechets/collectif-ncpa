NCPA — Logements collectifs

Accès aux données

Cet outil charge les données de suivi depuis le dépôt. Saisissez le mot de passe d'accès pour afficher la carte.

Mode d'emploi

Comprendre la carte

Un point = une adresse de logement collectif recensée sur le territoire.

Couleur : statut de livraison
Taille du point

Proportionnelle au nombre d'appartements (échelle en racine carrée, pour que les grandes résidences n'écrasent pas les petits immeubles). Un point semi-transparent signale un nombre d'appartements non renseigné.

Points à liseré pointillé

Adresses partageant des coordonnées strictement identiques avec d'autres : elles sont légèrement écartées en cercle pour rester cliquables. Position réelle conservée dans les exports.

Situations bloquées

Adresses non livrées dont le champ ÉTAT indique « PAS DE PLACE », « REFUS » ou « PRIVE ». Elles sont exclues du calcul d'avancement, comme les non livrables de l'outil Conteneurisation.
